ok ok ok, final payload structure but this time...concise :D

MAGIC — 4 bytes (ASCII, e.g. b'END0') 💿
MSGTYPE — 1 byte (enum: 1=file, 2=chunk, 3=ack, etc.) 💿
TOTAL_SIZE — 8 bytes (uint64) — total bytes for logical file/frame (useful for reassembly) 💿
CHUNK_INDEX — 4 bytes (uint32) — 0-based index of this chunk 📀
TOTAL_CHUNKS — 4 bytes (uint32) 📀
CHECKSUM — 4 bytes (crc32 of payload or chunk) 💿
DATACLASS — 4 bytes (uint32 or ASCII tag like b'IMG ' ) 💿
PAYLOAD_INDEX  4 bytes (length of extra if available) 
FILENAME_LEN — 2 bytes (uint16) — length of filename in bytes 📀
FILEPATH_LEN — 2 bytes (uint16) — length of filepath in bytes 📀
FILENAME — FILENAME_LEN bytes (utf-8) 📀
FILEPATH — FILEPATH_LEN bytes (utf-8) 📀
PAYLOAD — PAYLOAD_LEN bytes (the chunk or full compressed image) 💿
